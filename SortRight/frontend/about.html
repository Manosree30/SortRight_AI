About SortRight

The Deterministic AI Waste Classification Assistant for Indian Municipalities.

💡 Core Design Principle

Most waste-sorting apps fail because they ask generative AI to "hallucinate" disposal advice. In reality, municipal recycling rules are strictly deterministic and location-specific.

SortRight decouples perception from governance: The vision/language model only identifies WHAT the item is, its material, and its visible condition. A deterministic rules engine (rules.json) decides the category, special-handling flags, recycling potential, and step-by-step actions.

🛡️ Privacy by Design

  • Zero Image Storage: Photos captured via camera or uploaded are compressed purely in-memory (io.BytesIO) and sent directly to the model API. Images are never written to disk or saved to any database.
  • Zero Personal Tracking: No cookies, no user tracking, and scan history is stored solely inside your local browser storage (localStorage).
  • Secure Secrets: API keys are maintained strictly inside .env and excluded from version control.

🚀 Future Roadmap

The following features are planned for future versions beyond the initial hackathon prototype:

1. Multi-Item Scene Segmentation Overlay
Bounding boxes and category masks for scanning multiple waste items on a table simultaneously.
2. Barcode & Resin Identification Code (RIC) Scanning
Direct barcode lookup with brand packaging material databases (#1 PET, #2 HDPE, #4 LDPE, #5 PP).
3. Municipal Drop-Off Facility Map & GPS Navigation
Interactive Leaflet map showing nearest authorized E-Waste drop-off points and dry waste collection centers (MRFs).
4. Continuous Active Learning & Municipal Cloud Integration
Multi-city rules synchronization, real IoT bin aggregation, and sanitation fleet route optimization.
